Excel ID Folder Checker

Slug: excel-id-folder-checker

Đối chiếu ID trong Excel với folder ảnh và xuất báo cáo.

Cách dùng

  1. Chạy file .exe.
  2. Chọn file/folder theo hộp thoại (nếu có).
  3. Kiểm tra output tại thư mục đã chọn.

Update

Tool sẽ kiểm tra manifest tại /manifest/excel-id-folder-checker.json và nhắc khi có bản mới.
