Make Folder By Filename

Slug: make-folder-by-filename

Tạo thư mục theo tên file và move file vào đúng thư mục.

Cách dùng

  1. Chạy file .exe.
  2. Chọn file/folder theo hộp thoại (nếu có).
  3. Kiểm tra output tại thư mục đã chọn.

Update

Tool sẽ kiểm tra manifest tại /manifest/make-folder-by-filename.json và nhắc khi có bản mới.
