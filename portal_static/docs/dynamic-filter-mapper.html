Dynamic Filter Mapper

Slug: dynamic-filter-mapper

Lọc/mapping dữ liệu theo điều kiện, xuất file kết quả an toàn (atomic write).

Cách dùng

  1. Chạy file .exe.
  2. Chọn file/folder theo hộp thoại (nếu có).
  3. Kiểm tra output tại thư mục đã chọn.

Update

Tool sẽ kiểm tra manifest tại /manifest/dynamic-filter-mapper.json và nhắc khi có bản mới.
