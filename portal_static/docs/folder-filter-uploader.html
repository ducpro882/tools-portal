Folder Filter Uploader

Slug: folder-filter-uploader

Lọc/copy/move folder theo danh sách ID (phục vụ upload).

Cách dùng

  1. Chạy file .exe.
  2. Chọn file/folder theo hộp thoại (nếu có).
  3. Kiểm tra output tại thư mục đã chọn.

Update

Tool sẽ kiểm tra manifest tại /manifest/folder-filter-uploader.json và nhắc khi có bản mới.
