Image Folder Renamer

Slug: image-folder-renamer

Sắp xếp ảnh theo diện tích, rename theo thứ tự trong từng folder con.

Cách dùng

  1. Chạy file .exe.
  2. Chọn file/folder theo hộp thoại (nếu có).
  3. Kiểm tra output tại thư mục đã chọn.

Update

Tool sẽ kiểm tra manifest tại /manifest/image-folder-renamer.json và nhắc khi có bản mới.
