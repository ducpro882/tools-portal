Folder Rename By ID

Slug: folder-rename-by-id

Đổi tên folder theo mapping/ID từ Excel/CSV.

Cách dùng

  1. Chạy file .exe.
  2. Chọn file/folder theo hộp thoại (nếu có).
  3. Kiểm tra output tại thư mục đã chọn.

Update

Tool sẽ kiểm tra manifest tại /manifest/folder-rename-by-id.json và nhắc khi có bản mới.
